Zotero 中文社区（zoterocn.org）是什么网站？与 Zotero 官方是什么关系？

Zotero 中文社区（zoterocn.org）是由社区自发运营的非官方中文站点，集中提供 Zotero 插件商店与版本兼容速查、中文使用与开发教程、期刊收录与分区查询、中文引用样式指南以及开放 JSON 目录数据。本站与 Zotero 官方（Corporation for Digital Scholarship）无隶属关系，所有代码与收录规则均在 GitHub 公开。

在 Zotero 中文社区下载插件安全吗？安装包来自哪里？

本站不托管、不修改任何第三方插件安装包。插件详情页和社区插件市场中的下载按钮全部指向插件作者在 GitHub 或 Gitee 上的公开发布页直链；使用「Zotero中文社区」插件在 Zotero 内安装或更新前，还会弹窗展示插件名、版本号、来源仓库与安装包地址，需用户核对确认后才会下载。

Zotero 7、8、9、10 升级后怎么快速查哪些插件还能用？

可在首页或插件广场进入对应大版本的兼容清单（如 Zotero 10 兼容的插件、Zotero 8 兼容的插件、Zotero 7 兼容的插件），按作者在公开发布说明中声明的适配范围筛选；未声明适配范围的插件不作推定，建议点进详情页查看作者仓库确认。升级主版本前建议先完整备份本地数据目录。

插件目录的收录与排序遵循什么规则？

目录内的插件没有推荐位、没有付费置顶，也没有广告位，全部按同一套公开规则自动收录、排序与下架，支持按 GitHub 星标、最近更新、近一年更新频率、下载量与名称排序。唯一例外是本社区自己维护的开源「Zotero中文社区」插件，它在插件广场顶部单独展示，不参与目录排序与计数。

找不到想用的插件、发现信息有误，或者想提交新插件怎么办？

可直接在公开仓库 github.com/cnzotero/zotero-community 提交 Issue。符合收录条件的 GitHub 插件申请会由公开脚本自动核对并收录，信息更正与下架申请由维护者处理，全部处理记录公开可查。

插件信息整理自各项目公开资料,收录不代表对安全性或质量的背书。所有插件按同一套规则展示。
