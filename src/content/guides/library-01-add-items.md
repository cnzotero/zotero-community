# 把文献加进 Zotero 的几种方式

适用 Zotero 版本：桌面版 7 及以上，浏览器端需要另外安装 Zotero Connector。个别细节只在较新版本才有，文中会单独注明。

最后核对于 2026-11-17。核对方式：Zotero 官方文档，以及 Zotero 官方源代码中的简体中文界面文本。以下桌面与浏览器操作均**未实测**，菜单名称可能随版本变化，请以自己界面上的实际显示为准。

## 你要解决什么

刚开始用 Zotero，最常见的困惑是「同一篇论文，到底该怎么放进去」。官方文档给出的入口有四种：浏览器里一键保存、输入 DOI 或 ISBN 等标识符、把手头的 PDF 拖进来让 Zotero 识别、完全手动新建。它们的差别主要在题录（作者、标题、期刊、年份等信息）的质量和省事程度。

官方的建议很明确：能从网页保存就从网页保存，尽量避免手动录入；即使需要修改，也最好从 Zotero 保存下来的版本改起，而不是从空白条目开始。下面按这个先后顺序介绍。[官方说明：添加条目](https://www.zotero.org/support/adding_items_to_zotero)

## 操作步骤

### 1. 首选：在文章页用浏览器连接器保存

先确认两件事：桌面版 Zotero 已经打开，浏览器里装好了 Zotero Connector（安装方法见[安装 Zotero 与第一个文库](/guides/install-zotero)）。官方排错说明提到，连接器虽然也能直接存到网页版文库，但在桌面程序打开的情况下保存，结果通常更好。

1. 打开论文的**摘要页或详情页**，而不是 PDF 本身。连接器识别到文章时，工具栏上的保存按钮会变成期刊文章图标；在图书馆目录的图书页面上，会变成图书图标。
2. 点击保存按钮，Zotero 会用页面上识别到的信息新建一个条目。在不少网站上，它还会顺带保存页面上可获取的 PDF，或为该条目找到的开放获取 PDF。
3. 点击后会弹出一个小窗口，显示条目要存进哪个分类。可以在这里改选其他分类或文库，也可以顺手加标签。Zotero 8 起，这个弹窗还能自动补全文库里已有的标签，并允许保存时附上一段笔记。[Zotero 8 发布说明](https://www.zotero.org/blog/zotero-8/)
4. 如果页面上有多篇文献（例如检索结果列表），按钮会变成文件夹图标，点击后可在弹出窗口里勾选要保存的几篇。

把鼠标停在保存按钮上，提示文字会显示这一页要用哪个「转换器」（translator，即针对某个网站抓取题录的脚本）。官方说明指出：同一篇文献在不同网站上的题录质量可能不一样，例如从出版社网站保存，通常比从 Google Scholar 保存的数据好得多。如果自动选的转换器不理想，可以右键点击保存按钮（Safari 中为在页面空白处右键），从列出的选项中换一个。

### 2. 已知 DOI、ISBN 等编号：用标识符添加

手里有编号时，这是最快的方法。官方文档列出的可用编号有：ISBN、DOI、PubMed ID（PMID）、arXiv ID 和 ADS Bibcode。

1. 点击 Zotero 工具栏里的「通过标识符添加条目」按钮（英文为 Add Item by Identifier；较新版本的菜单里也可能显示为「根据标识符新增…」）。
2. 粘贴或输入编号，按回车。一次要加多条时，编号之间用空格、逗号或换行分开。

据官方说明，Zotero 会去这些地方查题录：ISBN 查美国国会图书馆、WorldCat 等目录；DOI 查 Crossref 等注册机构；PMID 查 NCBI PubMed；arXiv ID 查 arXiv.org；ADS Bibcode 查 ADS。查不到时，可以改用第 1 种方法。

### 3. 手头已有 PDF：拖进来，让 Zotero 识别元数据

适合把以前下载在电脑里的一批 PDF 搬进 Zotero。[官方说明：检索 PDF 元数据](https://www.zotero.org/support/retrieve_pdf_metadata)

1. 把 PDF 从文件夹拖进 Zotero 中间的条目列表（放在条目之间或空白处），或拖到左侧某个分类上。它会先作为一个**独立附件**存进来。
2. 默认情况下，Zotero 会自动为 PDF 检索元数据：识别成功就新建一个上级条目，把 PDF 挂在下面，并按题录给文件改名。这个自动行为可以在设置的「常规」中关闭（中文界面选项为「自动检索 PDF 和电子书的元数据」）。
3. 如果识别结果不满意，右键点击新生成的上级条目，选「撤消检索元数据」，PDF 会恢复为独立附件，方便你换别的方式处理。

识别失败、只剩独立附件时，官方给了三个办法：

- 在网上找到这篇文献的页面，用第 1 种方法保存出正式条目，再把 PDF 拖到这个新条目上，变成它的附件。
- 右键点击这个 PDF，选「创建上级条目…」，输入 DOI 或 ISBN 等编号来获取题录。
- 实在找不到来源，在「创建上级条目」窗口里点「手动录入」，自己填写。

需要了解的工作原理：官方说明写明，识别功能会把 PDF 前几页的文字发送到 Zotero 的网络服务，结合 Crossref 已知数据和 DOI、ISBN 查询来生成条目；该服务不需要 Zotero 账号，也不记录检索内容与结果。学术论文 PDF 通常能识别得比较好；其他类型的文档只是碰巧做成了 PDF，未必带有可用的标准元数据，不要指望一定能识别。

官方同时提醒：这个功能适合批量导入旧资料，但不是日常添加文献的最佳方式。从文章页用连接器保存，步骤更少，题录也往往更准。

### 4. 最后的办法：手动新建条目

只在网上实在找不到的资料（例如没有公开信息的内部材料）才需要手动录入。

1. 点击中间栏上方绿色的「新建条目」按钮，在下拉菜单里选条目类型。菜单第一层显示最近用过的类型，完整列表在「更多」里。
2. 中间列表会出现一个空条目，在右侧的信息区逐项填写。修改会自动保存，不需要另外点保存。

注意：「网页」类型不在这个菜单里。官方的解释是，网页几乎总是用浏览器保存更好；确实要手动建网页条目时，可以先建一个其他类型的空条目，再在右侧把条目类型改成「网页」。

### 5. 不论用哪种方式，保存后马上核对

官方文档特别强调，任何文献管理软件保存下来的题录都应当核对。常见问题包括：期刊名错、作者缺漏或顺序不对、作者只有姓和首字母、标题大小写不统一等。英文标题官方建议统一存成「句首大写」（sentence case），因为软件能把它可靠地转成标题大小写，反过来却做不到。

如果某个网站总是给出错误数据，可以带上示例网址或编号到 Zotero 官方论坛反馈，开发者有可能据此修正。

## 常见问题

**保存按钮一直是灰色的网页图标，怎么办？** 灰色网页图标表示连接器没有在这页识别到文献信息，此时保存只会得到一个包含标题、网址和访问日期的「网页」条目。官方排错建议依次检查：确认是在受支持网站的文章页上；刷新并等页面完全加载；所有网站都这样时重启浏览器；先打开桌面 Zotero 再保存；检查连接器与浏览器是否为最新版本；确认已允许连接器访问所有网站。[官方排错说明](https://www.zotero.org/support/troubleshooting_translator_issues)

**一次要导入几百篇，可以连续点保存吗？** 官方说明提醒，Google Scholar、ProQuest、Web of Science 等数据库在短时间内频繁或大量保存时，可能会暂时封锁访问。批量导入时更稳妥的办法是在数据库里批量导出 RIS、BibTeX 等标准格式文件，再导入 Zotero。

**拖进来的 PDF 为什么没有变成正式条目？** 说明自动识别没有找到匹配的题录。按第 3 步的三个办法给它补一个上级条目即可。官方说明指出，独立附件没有题录，无法用于引用，很多检索功能也用不了，因此尽量不要让文件长期以独立附件的形式留在文库里。

**中文网站能用连接器保存吗？** 取决于该网站有没有可用的转换器，以及网站是否改版。详见[中文文献入库要注意什么](/guides/chinese-items)。
