我的 Zotero 版本

下载 v0.2.1(.xpi)zotero-2-eagle.xpi · 来自 github.com

怎么安装?
  1. 保存下载的 .xpi 文件,不要解压。
  2. 打开 Zotero,菜单选择「工具 → 插件」。
  3. 点右上角齿轮,选「Install Plugin From File…」,选中刚下载的文件。
  4. 按提示重启 Zotero。
