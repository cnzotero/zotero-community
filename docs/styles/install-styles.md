# 引用样式怎么安装

![](../assets/cover-04-citation-styles.png)

适用 Zotero 版本：桌面版 7 及以上；样式管理入口名称以当前版本为准。

最后核对于 2026-11-11。核对方式：Zotero 官方样式文档；以下操作**未实测**。

## 你要解决什么

让引文和参考文献按学校或期刊要求显示，先找对样式，再检查题录与输出。引用样式与功能插件不是一回事：前者决定参考文献怎样排列，后者扩展软件能力。看到安装文件时先分清用途，不要把样式文件送进插件窗口。本文只说明安装和核对，不保证名字相近的样式就完全符合投稿要求。[官方引用样式说明](https://www.zotero.org/support/styles)

## 操作步骤

### 1. 找到明确的格式要求

保存学校或期刊最新的参考文献要求，确认是顺序编号还是作者与年份形式，是否规定某个标准的版本，以及给出的示例。记录要求的来源和日期，不只凭同学的旧论文判断。若只写了一个大类名称而缺少细则，先向负责单位核实，再用真实条目做样式比较。

<!-- 截图:公开投稿须知中的参考文献要求与日期 -->

### 2. 在官方样式库中找候选

打开 [Zotero 样式库](https://www.zotero.org/styles)，按期刊名称或样式名称查找；也可从 Zotero 设置里的引用样式管理处寻找更多样式。比较完整名称，不把相似期刊当成目标期刊。找到候选后保留来源地址，便于以后核对更新或反馈问题；具体入口请以[官方文档](https://www.zotero.org/support/styles)为准。

<!-- 截图:官方样式库的候选名称与来源 -->

### 3. 完成安装并确认可选

按官方页面或 Zotero 当前窗口的提示安装；若手头已有可信来源的 `.csl` 文件，可在样式管理处选择本地文件添加。文件来源不清时不要直接使用，也不要把网页另存文件当成样式。安装后检查它是否出现在可选列表中，并确认名称符合原先找到的候选。

<!-- 截图:样式管理处显示新添加的样式 -->

### 4. 用几种条目核对输出

选取公开演示文献中的中文期刊、外文期刊和图书等条目，先核对作者、年份、刊名、卷期与页码，再查看对应样式输出。将作者顺序、标点、题名、日期与要求逐项比对。某一个示例正确不能代表所有类型都正确，尤其注意网上资源、无日期或多人作者等容易混淆的情形。

<!-- 截图:演示条目的题录与参考文献输出并排对照 -->

### 5. 在写作文档中选择样式

如果使用 Word 中的 Zotero 引文功能，还需要在该文档的文档偏好里选择合适样式，而不是只在桌面程序里装好就结束。先在文档副本中检查一处引文与文末参考文献，再用于正式稿。不要为了修一个标点而立即把整篇引文改成普通文字。

<!-- 截图:演示文档的样式选择与参考文献列表 -->

## 常见问题

**安装后旧稿没变化怎么办？** 核对旧稿是否使用 Zotero 引文，以及该文档选的样式；具体用法见[官方 Word 说明](https://www.zotero.org/support/word_processor_plugin_usage)。

**样式看着不对就一定是样式错误吗？** 先核对条目字段与当前要求，再判断差异来自资料还是样式，不要只看名称。
