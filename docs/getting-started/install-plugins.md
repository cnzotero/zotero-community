# 怎么安装 Zotero 插件

![](../assets/cover-02-find-install-plugins.png)

适用 Zotero 版本：桌面版 7 及以上，单个插件的适配范围以作者说明为准。

最后核对于 2026-11-11。核对方式：官方文档与社区插件说明；以下操作**未实测**。

## 你要解决什么

安装插件前，先说清楚自己要补上哪一项能力，再确认 Zotero 本身是否已经提供。插件不是越多越好；来源、适配范围与操作结果，比安装数量更重要。本篇帮助你从作者发布页取得正确文件，再在 Zotero 中完成一次可核对的安装。插件能够访问电脑和文库，只应安装可信作者的作品。[官方插件说明](https://www.zotero.org/support/plugins)

## 操作步骤

### 1. 记下 Zotero 与插件的版本

在 Zotero 的版本信息中记下完整版本号，再去作者主页阅读当前安装说明。确认作者声明的最低与最高适配范围，而不只看帖子标题写着「最新版」。如果作者没有说明，请先询问；社区显示「未声明」表示缺少明确依据，不能据此保证能用，也不能直接断定不能用。

<!-- 截图:Zotero 版本信息与作者适配说明，使用公开资料 -->

### 2. 从作者发布页取得安装包

在作者自己的发布页寻找对应版本的 `.xpi` 文件，核对文件名与发布日期。网页提供的源文件压缩包通常不是直接安装用的文件，不要靠修改后缀把它伪装成安装包。下载地址不明、页面要求运行陌生命令或额外安装不相关软件时，先停下来核对说明。

<!-- 截图:作者发布页中安装包所在位置，不突出单个插件 -->

### 3. 在 Zotero 中发起安装

打开 Zotero「工具 → 插件」，按照当前窗口提供的方式选择已下载的安装包。官方文档也说明可将安装包拖入插件窗口；具体提示与中文名称请以所用版本为准。操作前保存当前工作，读完确认内容后再继续，不要在没有识别来源时反复点击确认。

<!-- 截图:插件窗口与本地安装文件的选择过程 -->

### 4. 确认结果，再做一个小范围试用

查看插件列表是否出现所选插件，以及是否需要重启。重启后先用公开示例或少量测试条目检查作者说明的基本功能，确认没有意外行为，再用于日常工作。保留这次安装的版本与来源信息，后续反馈问题时能准确说明；安装成功本身不代表所有功能都已验证。

<!-- 截图:安装后的插件列表与明确状态提示 -->

## 常见问题

**浏览器扩展能用这套方法安装吗？** 不能混用。Connector 由浏览器管理，Zotero 插件在桌面程序内管理；先确认文件类型与用途。

**显示不兼容，能强行装吗？** 不建议绕过适配提示。应寻找作者明确支持当前版本的安装包，或向作者说明版本询问。

**安装后找不到入口怎么办？** 查作者的使用说明与重启要求。不同插件入口不同，不要假定都出现在同一个菜单里。
