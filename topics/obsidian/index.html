Zotero Obsidian 与 Markdown 插件

这类插件把 Zotero 的文献条目、PDF 高亮批注与笔记同步或导出到 Obsidian、Notion、Logseq 或标准 Markdown 文件。选择时可核对模板自定义能力、同步方向（单向导出还是增量更新），以及变更后是否覆盖已有手写笔记。

← 返回插件广场

共 26 款,按 GitHub 星标排序,与分类页使用同一规则。收录规则：插件名称或简介中出现「obsidian」「markdown」「logseq」「notion」「双向链接」「md 笔记」等词。所有插件按同一规则判断，不看作者、不看星标，没有人工指定。
