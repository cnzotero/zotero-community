# 文库不见了，如何准备恢复

适用 Zotero 版本：桌面版 7 及以上；不同版本的恢复要求请逐项核对官方说明。

最后核对于 2026-11-11。核对方式：官方数据恢复文档；以下恢复准备与检查**未实测**，不提供直接覆盖现有文库的操作。

## 你要解决什么

先保全现状，分清是看错文库、附件打不开、误删，还是原电脑损坏，再选择有依据的恢复方式。空列表并不自动表示原来的资料已经丢失；看到旧备份也不代表它含有全部附件。不要先重装、删除文件或反复同步试运气。[官方恢复说明](https://www.zotero.org/support/zotero_data#restoring_your_zotero_data_from_a_backup)

## 操作步骤

### 1. 停止继续改变资料

暂停整理与批量操作，记录何时发现问题、最后一次正常使用的时间，以及最近是否换电脑或改过设置。若怀疑错误已经同步，先按官方说明暂停自动同步，不要立即再次同步。保留当前错误提示，不要为了截图重复触发会删除或改写内容的动作。

<!-- 截图:脱敏的问题现象与发生时间记录 -->

### 2. 确认正在看的位置

检查当前选择的是不是自己的文库、某个空分类或筛选结果；如涉及账号，核对是否确实是原账号。按照官方文档定位正在使用的数据目录，记录情况，但不要此时删除或更换它。若仍无法确认，先停止操作并通过[官方帮助入口](https://www.zotero.org/support/getting_help)求助，不猜测哪个旧文件夹才正确。

<!-- 截图:演示文库选择与无筛选状态，不显示个人资料 -->

### 3. 关闭 Zotero，完整保全现状

确认 Zotero 已退出，再按[官方数据说明](https://www.zotero.org/support/zotero_data)保存当前完整数据目录的副本，并单独保全放在文库之外的附件。不要只拿一份导出的参考文献清单替代；也不要让新的备份覆盖唯一的旧备份。原目录、当前副本与候选备份都先保留，确保后续出错还有回到原状的依据。

<!-- 截图:多份有日期的示例副本，隐藏真实保存位置 -->

### 4. 核对候选恢复来源

确认候选副本的日期、Zotero 版本、包含范围以及是否有需要的附件；如果只有自动备份，不能假定同时含有附件文件。若曾经同步，可先在网页只查看在线文库是否完整，不急着让它与本机互相更新。拿不准来源、版本或哪份才是正确资料时，保留现状并求助，不继续替换。

<!-- 截图:候选副本的日期与内容核对清单 -->

### 5. 确认能回退后再按官方方案恢复

准备好现状副本并确认恢复来源后，才逐项阅读适合自己情形的官方步骤；实际替换必须在 Zotero 关闭时进行，并保留原有资料。恢复后先核对条目、笔记、分类及多份附件，不要立即恢复自动同步。误删若已经同步，后续同步可能再次应用错误改动；此时先向官方求助，不能凭看到旧资料就认为问题已彻底解决。

<!-- 截图:恢复后的演示条目与附件核对，未连接真实账号 -->

## 常见问题

**可以把旧文件直接盖到现在的文库上吗？** 不应这样做。先保存完整现状，确认版本、来源和回退方法，再遵照官方对应方案。

**找回题录但附件打不开怎么办？** 分别检查副本是否包含附件、原来是否使用外部链接以及文件是否仍存在；不要反复导入同一批题录。
