Zotero 文献检索插件

文献检索类插件在 Zotero 内查找、发现或导入新文献。可比较它连接的数据库范围、是否支持中文检索词、结果如何导入文库，并留意各数据来源的使用条件。

← 返回插件广场

共 14 款,按 GitHub 星标排序,与分类页使用同一规则。收录规则：插件名称或简介中出现「文献检索」「检索」「搜索」「literature search」「paper search」「discover」等词。所有插件按同一规则判断，不看作者、不看星标，没有人工指定。
