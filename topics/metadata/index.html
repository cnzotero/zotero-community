Zotero 元数据补全插件

元数据类插件补全或校对题名、作者、标识符等条目信息。使用前请了解信息来源和修改范围，批量处理前先用少量条目试一遍，重要字段仍需结合原文核对。

← 返回插件广场

共 15 款,按 GitHub 星标排序,与分类页使用同一规则。收录规则：插件名称或简介中出现「元数据」「metadata」「doi」「isbn」「抓取」「scrap」等词。所有插件按同一规则判断，不看作者、不看星标，没有人工指定。
