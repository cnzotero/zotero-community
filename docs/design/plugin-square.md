# 插件广场 · 设计稿(v1)

> 状态:设计稿,待开发。目标页面:`/plugins`(列表)与 `/plugins/:owner/:repo`(详情)。
> 约束:本仓库公开。设计与文案只讲用户价值;不出现任何内部信息;所有插件使用同一套排序与展示规则,不设置顶位和推荐位。

## 1. 目标与不做什么

**目标:** 让中文用户在 30 秒内回答三个问题——这个插件做什么?我的 Zotero 版本能用吗?它还有人维护吗?

**不做(v1):** 一键安装(Zotero 不允许网页直接装)、用户评分与评论(需要账号,等论坛后端)、下载量统计(只有 GitHub 数据,口径不全,先不展示)。

## 3. 分类(10 类,单选 + 「全部」)

| 键 | 中文 | 说明 |

| attachment | 附件 | PDF 与文件管理、同步 |
| integration | 集成 | 与 Word、Obsidian、其他工具联动 |

## 5. 数据模型(`src/data/plugins.json`,由脚本生成)

```ts
interface Plugin {
  id: string;            // "owner/repo" 小写
  name: string;          // 显示名,优先中文名(英文名)
  summary: string;       // 中文摘要 ≤ 120 字
  category: CategoryKey; // 见第 3 节
  tags: string[];        // 仅详情页展示
  author: string;
  homepage: string;      // https://github.com/owner/repo
  license: string | null;
  stars: number;
  latest: { version: string; date: string; releaseUrl: string } | null;
  zotero: { min: string | null; max: string | null }; // 作者声明的兼容范围,可能缺失
  monthlyReleases: number[]; // 近 12 个月每月发布次数,长度 12
}
```

- 兼容判断:`zotero.min/max` 缺失时显示「兼容范围未声明」,**不**默认为兼容。
- 「适配 Zotero N」筛选:`min ≤ N ≤ max`(`*` 通配);未声明的不被任何版本筛选命中,但在「全部」里正常出现。
- 数据来源:各插件在 GitHub 上的公开信息(仓库元数据与发布记录)。`scripts/refresh-plugins.mjs` 调 GitHub 公开接口刷新,令牌只从环境变量读取,**不进仓库**;每天或每周由维护者手动运行并提交 JSON。
- 页面底部固定一行说明:「数据整理自各项目公开信息,收录不代表对其安全性或质量的背书。」

## 6. 排序与展示规则(对所有插件一视同仁)

- 排序选项:**热度**(星标,默认)· **最近更新**(最新发布日期)· **名称**(拼音/字母)。
- 无置顶、无「推荐」徽标、无广告位。
- 同分时按名称排序,保证结果稳定。
- **每张卡片固定四个标签**(顺序固定,数据缺失也不少):
  1. 分类(如「阅读」)
  2. 适配版本(「适配 Zotero 7–10」/「适配 Zotero 7/9」/「兼容范围未声明」)
  3. 维护状态:近期更新(≤90 天)· 维护中(≤1 年)· 更新放缓(≤2 年)· 久未更新(>2 年)· 更新未知
  4. 人气档位:热门(★≥3000)· 常用(≥500)· 成长中(≥100)· 小众(<100)
  标签只作提示,不隐藏任何插件;人气只反映热度,不代表质量。

## 7. 交互与状态

- 搜索:前端本地检索(名称、作者、摘要、标签),输入防抖 120ms;高亮不做。
- 筛选、排序、搜索词都写进 URL 查询参数(`?cat=reading&zv=10&sort=updated&q=翻译`),可分享、可回退。
- 空结果:展示空状态插画 +「没有符合条件的插件」+「清除筛选」按钮。
- 加载:数据是随包静态 JSON,无加载态;详情页路由未命中时展示 404 空状态并回列表。
- 键盘:卡片可 Tab 聚焦,Enter 进入;chips 有可见焦点环;所有图标按钮有 `aria-label`。
- 深色模式:沿用站点已有深浅色变量;插画提供浅色与深色两版。

## 8. 视觉规范

沿用现有变量,不新增主色:

- 色系偏红(靠近 Zotero 的暖红气质,但不仿造其标志):强调色 `#cc2936`(深色模式 `#ff8a93`)/ 悬停 `#a81f2b`(深色 `#ffb3b9`)/ 墨色 `#1f1517` / 底 `#fcf9f7` / 雾面 `#fbeeec` / 线 `#efe2df`;深色底 `#1a1214`,卡片 `#241a1c`。
- 备选皮肤:原蓝色方案(强调色 `#1f3b73`)可作为第二套主题,以后做主题切换时再启用。
- 卡片:圆角 12,1px 线框,悬停时线框变强调色并上移 1px(已实现)。
- 兼容徽标:`适配 Zotero 7–10`——全覆盖用强调色底;部分覆盖用雾面底;未声明用虚线框。
- 星标数字用 `12.2k` 缩写;日期用相对时间(「3 天前」),悬停显示绝对日期。
- 插画风格:扁平几何、少量线条、留白多,安静的学术气质;不使用 Zotero 的标志、红色「Z」造型,不画任何真实品牌标志。

## 10. 开发分期

- **P1(本期)**:列表页(搜索、分类、版本筛选、排序、URL 同步)、详情页、数据脚本与首批数据、统计条、空状态、手机适配。
- **P2**:更新节奏小图、相关插件、`refresh-plugins` 的 CI 化(定时更新 JSON)。
- **P3**:账号体系接入后——评分与评论、「我用过」标记。

## 11. 验收清单(P1)

- [ ] 搜索、分类、Zotero 版本、更新时间、排序组合使用结果正确,并同步到 URL。
- [ ] 兼容范围未声明的插件不会被「适配 Zotero N」命中,也不会被标成兼容。
- [ ] 所有插件用同一排序规则,页面上没有置顶或推荐标记。
- [ ] 手机、平板、桌面三档布局无横向滚动;深浅色都清晰。
- [ ] 键盘可完成全部操作;焦点环可见。
- [ ] 类型检查、单元测试、构建通过;`dist` 体积增量 ≤ 200KB(gzip 前)。
- [ ] 仓库内无令牌、内部地址或与运营方相关的字样。
