# 插件装不上怎么办：先按版本核对

适用 Zotero 版本：桌面版 7 及以上，其他版本请查作者与官方说明。

最后核对于 2026-11-11。核对方式：官方帮助文档；以下排查操作**未实测**。

## 你要解决什么

把「装不上」拆成可以说明的问题：下载失败、安装被拒绝、安装后停用，还是装好后找不到入口。它们需要的证据不同，反复换文件或重装 Zotero 往往不能说明原因。先保存错误提示与版本，再做一次有记录的排查；如果涉及文库异常，不要为了试插件而删除资料。[官方求助建议](https://www.zotero.org/support/getting_help)

## 操作步骤

### 1. 明确失败发生在哪一步

记录从哪里下载、下载到什么文件、在哪个窗口安装，以及最后出现的完整提示。用一句话分别写出「我希望发生什么」和「实际发生什么」。不要只发一句「不能用」或裁掉上下文的红字；分享截图前遮住个人姓名、账号和文献内容，保留软件版本与错误文字即可。

<!-- 截图:安装失败提示与所在窗口，所有私人信息已遮去 -->

### 2. 对照作者声明的适配范围

查看 Zotero 的完整版本号、操作系统和插件版本，再对照作者主页与发布说明。某个旧插件支持过去的大版本，并不代表支持现在的版本；发布时间较新也不自动代表适配。如果页面与安装包说明相互矛盾，把两处链接一并提供给作者，而不是自行改动适配限制。

<!-- 截图:版本对照表，只列示例版本和公开说明 -->

### 3. 核对下载的文件与来源

回到作者发布页确认取得的是 `.xpi` 安装包，而不是网页、源文件压缩包或下载未完成的文件。若浏览器提示下载失败，先核对网络与来源，再重新获取一次；不要从陌生镜像随意补一个同名文件。若作者已经撤下某个版本，停止使用来历不明的副本。

<!-- 截图:下载文件类型与作者发布页的对应关系 -->

### 4. 分清安装问题与使用问题

按[官方安装方法](https://www.zotero.org/support/plugins)在插件窗口重新核对一次状态，依提示重启后查看作者列明的入口。能在列表中看到插件但功能异常，属于另一类问题，应描述具体操作。若作者建议停用其他插件排查，先记录原来的启用状态，每次只改变一个条件，不要一次删除多项内容。

<!-- 截图:插件列表中的启用状态与版本 -->

### 5. 把材料交给正确的维护者

第三方插件自身问题优先交给作者；社区目录写错适配信息时，向社区[提交更正](https://github.com/cnzotero/zotero-community/issues/new?template=correct-info.yml)。附上最少可重复步骤、版本和公开依据。普通反馈不要附整份文库；疑似安全问题应先阅读[安全说明](../../SECURITY.md)。

<!-- 截图:脱敏后的反馈材料清单 -->

## 常见问题

**要不要直接重装？** 先核对错误与官方说明。尚未确定原因时，不应删除文库或应用资料。

**换旧版就能解决吗？** 不作这种保证。应同时核对插件、Zotero 与已有文库的适用要求，避免反复尝试扩大问题。

**社区能修改第三方插件吗？** 社区可以核对目录与指向作者的说明，插件本身的修复由相应作者处理。
