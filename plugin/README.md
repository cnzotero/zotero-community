# Zotero中文社区 · 插件市场

Zotero 中文社区(<https://zoterocn.org>)的官方 Zotero 插件:在 Zotero 里浏览、搜索、安装与更新本站插件广场收录的插件。

- 插件标识:`zotero-community@zoterocn.org`
- 适配:Zotero 7 至 10(`strict_min_version` 为 `7.0`,`strict_max_version` 为 `10.*`)。上限写到当前已发布的最新大版本为止:Zotero 每个大版本都可能改动插件接口,未验证的版本不提前声明;新的大版本发布并验证后,发布新版本把上限提高即可。
- 形态:Zotero 7+ 的引导式插件(`bootstrap.js` + `manifest.json`),没有任何运行时依赖。

## 安装

1. 在本仓库的 Releases 页下载 `zotero-community.xpi`(标签形如 `plugin-v1.0.0`)。
2. 打开 Zotero,菜单「工具 → 插件」,点右上角齿轮,选「从文件安装附加组件…」,选择下载的文件。
3. 安装后,文库工具栏里搜索框左侧会出现「插件市场」按钮(提示文字为「Zotero 中文社区 · 插件市场」),点它打开。

「工具」菜单里默认不放入口。需要的话,在 Zotero 设置的「高级 → 设置编辑器」里把 `extensions.zotero-community.showToolsMenuItem` 改为 `true`,重启 Zotero 后「工具」菜单里也会出现这一项。

之后的版本更新由 Zotero 按本仓库 GitHub 上的更新清单自动检查:`https://github.com/cnzotero/zotero-community/releases/download/release/update.json`。更新清单与安装包都放在 GitHub 上,不放在 zoterocn.org:即使站点出了问题,也不能借自动更新给你推送别的代码;清单里还带有安装包的 SHA-256,Zotero 下载更新后会核对。

## 能做什么

- 列出本站在架的全部插件,可按名称、简介、作者搜索,按分类筛选。
- 默认只显示作者声明适配当前 Zotero 大版本的插件,可以取消勾选查看全部。
- 排序与站点一致:星标最多(默认)、最近更新、更新最勤(近一年有发布的天数)、下载最多;同分按名称。
- 每张卡片显示名称、作者、简介、星标、最新版本与日期、适配范围,以及本机的安装状态:已安装 / 可更新 / 未安装。目录里没有该插件标识的,显示「安装后可在附加组件里查看」,不显示「已安装」。
- 安装或更新前弹出确认框,写明插件名、版本、来源域名与安装包地址;确认后才下载安装,并提示结果(成功、失败原因、是否需要重启)。
- 「查看详情」在系统浏览器里打开该插件在 zoterocn.org 上的介绍页。
- 界面跟随 Zotero 的深浅色主题。

## 数据来源

插件信息来自本站公开的目录数据 <https://zoterocn.org/data/catalog.json>,由站点每天构建时根据各插件仓库的公开信息生成,只含在架的插件(下架规则见站点的收录规则页)。

- 打开插件市场时读取一次:10 秒超时、不跟随跳转、只接受 JSON、超过 8MB 立即停止读取。
- 成功后保存一份到 Zotero 配置目录下的 `zotero-community/catalog-cache.json`。读取失败时显示原因与「重试」按钮,有保存的目录就先用它,并标明是离线缓存。
- 保存的目录最多使用 30 天,超过当作没有;每次读回都重新校验。新取到的目录如果比已保存的更旧,不采用。

## 一视同仁

插件市场里的所有插件使用同一套筛选、排序与安装规则,没有推荐位、没有置顶、没有按插件或作者区分的特殊处理(本插件自己不在插件市场的列表里)。插件市场的代码里有测试检查这一点。

## 安全

- 只会安装目录里该插件适配当前 Zotero 版本的那条发布记录的安装包。地址必须:
  - 是 `https://github.com/…` 上以 `.xpi` 结尾的文件(只认 GitHub,主机写死在插件里,不随目录变化),不带查询串、锚点、端口或用户名,且与标准化后的地址逐字一致;
  - 路径里没有 `%` 编码,没有 `.`、`..` 或空的路径段;
  - **在这个插件自己的 GitHub 仓库里**:路径前两段 `owner/repo` 与插件 id 相同(不区分大小写)。别的仓库、其它网站上的同名仓库里的安装包一律拒绝,即使它声称是同一个插件。
- 目录解析、缓存读回、选择版本、点击安装时都用同一套校验;不通过的发布记录被丢弃,不通过就拒绝安装并提示。
- 确认框显示完整来源(如 `github.com/owner/repo`)与安装包地址,两者都由同一个下载地址得出。
- 下载完成后、安装之前,核对安装包里的插件标识与目录记录是否一致,不一致就取消安装并提示。
- 插件名称与简介去掉控制字符与双向文字控制符(防止伪装显示),并限制长度。
- 插件市场窗口有内容安全策略:只运行 Zotero 与本插件自带的脚本,网络请求只允许到 zoterocn.org。
- 不接受来自目录以外的任何安装地址。
- 本社区不托管安装包,安装包都来自作者自己的发布页。收录不代表对插件安全性或质量的背书,安装前请确认来源可信。

## 隐私

插件与 Zotero 因为本插件而访问的网络地址只有这些:

1. **插件目录**:打开插件市场时读取 `https://zoterocn.org/data/catalog.json`(不带 Cookie,不跟随跳转)。
2. **本插件的更新清单**:Zotero 自身定期检查插件更新时,读取 `https://github.com/cnzotero/zotero-community/releases/download/release/update.json`;有新版本时,从同一仓库的 Release 下载安装包。GitHub 的下载地址会跳转到 GitHub 的文件分发服务器(`*.githubusercontent.com`)。
3. **你确认安装的插件**:只有在确认框里点了「安装 / 更新」之后,才从确认框里显示的地址(该插件在 github.com 上的仓库)下载安装包;同样可能跳转到这些网站的文件分发服务器。
4. **「查看详情」**:在系统浏览器里打开 `https://zoterocn.org/plugins/<作者>/<仓库>`,由浏览器访问,与插件无关。

插件不收集、不上传任何用户信息,也不读取你的文献库。

## 开发

```bash
cd plugin
npm test        # 纯逻辑与结构测试(node --test)
npm run build   # 生成 dist/zotero-community.xpi 并校验包结构
```

- 纯逻辑在 `addon/content/lib.js`(目录解析与校验、适配判断、排序、搜索、安装包地址白名单、版本比较、安装状态),在 Node 里直接测试。
- 站点的测试会用同一份 `lib.js` 读取站点生成的目录数据,核对四种排序、搜索与适配筛选的结果与站点一致。
- 打包可复现:文件按名称排序、修改时间与权限统一固定、不带系统扩展属性,同一份源码用同一版本的 `zip` 工具会得到逐字节相同的安装包(不同版本的 `zip` 工具压缩结果可能不同)。`npm run build` 同时生成 `dist/update.json`,发布时上传。
- 本地试用时,请用全新的临时配置目录启动 Zotero,不要动日常使用的配置与数据目录,例如:
  `zotero -profile <临时目录>/profile -no-remote -datadir <临时目录>/data -ZoteroDebugText`,
  并把 xpi 复制为 `<临时目录>/profile/extensions/zotero-community@zoterocn.org.xpi`。
- 开发自检:在临时配置里设置 `extensions.zotero-community.selfTest` 为 `true`,启动后插件会检查工具栏按钮的位置与尺寸、经按钮打开插件市场、新开一个主窗口检查按钮,再检查列表、筛选、排序、确认框(打开后点取消,不安装任何插件),再停用、启用一次插件检查清理,结果写在调试输出里(以 `[zotero-community] selftest:` 开头)。日常使用不会有这个设置。

发布流程见 [RELEASING.md](RELEASING.md)。
