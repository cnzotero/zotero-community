收录与数据规则

插件广场收录什么、不收录什么、怎么排序、怎么申请收录或下架。规则对所有插件一视同仁。

1. 收录范围

收录面向 Zotero 7 及以上版本的插件,即以 .xpi 安装包发布、可在 Zotero 的「工具 → 插件」里安装的扩展。仅适配 Zotero 6 及更早版本的插件不再收录。

2. 收录标准

  • 源码可见:项目有公开的代码仓库(GitHub 或 Gitee),便于用户查看来源与更新记录。
  • 可获取安装包:在发布页提供 .xpi 安装包,本站的下载按钮只会指向作者自己的发布页。
  • 用途真实:名称与简介和实际功能相符,不夸大、不误导。
  • 没有已知的恶意行为:不得窃取数据、静默上传用户内容、植入广告或捆绑与功能无关的软件。
  • 遵守法律法规:不含违法违规内容,不侵犯他人知识产权。

卡片上的维护状态标签只是提示。插件是否展示,只看第 3 章写明的下架条件。

3. 不收录与下架的情形

自动下架。每次更新数据时,本站按同一套条件把所有插件重新判断一遍,满足下面任意一条就会下架:

  1. 超过 1 年未发布,且没有可下载的安装包:最近一次发布距今超过 1 年(365 天),或者没有任何发布记录,并且在作者的发布页上找不到可以下载安装的 .xpi 安装包。近 1 年内有发布的插件不会因为这一条下架;本站暂时没有收录到安装包的,详情页只提供仓库链接。
  2. 最近一次发布超过 2 年:最近一次发布距今超过 2 年(730 天)。
  3. 超过 1 年未发布,且未声明适配当前 Zotero 版本:最近一次发布距今超过 1 年(365 天),并且作者没有声明适配的 Zotero 版本,或声明适配的最高版本低于目前最新的 Zotero 大版本(目前是 Zotero 10)。
  • 恢复是自动的:作者发布新版本、不再符合上面任何一条后,本站下一次更新数据时会自动重新上架,不需要申请。
  • 下架记录公开:每个下架插件的原因、最近一次发布日期与下架日期列在已下架插件与原因里。目前在架 348 款,已下架 39 款。
  • 「距今」按本站更新数据、重新生成页面的日期计算;仓库已归档本身不是下架理由。

人工下架。以下情形经核实后下架:

  • 存在恶意行为,或经核实有严重的安全问题且作者长期未处理。
  • 侵犯他人权利,且权利人提出有效的投诉。
  • 安装包长期无法下载,且仓库已删除或归档、无人维护。
  • 作者本人提出下架,并能证明其对该项目的所有权(例如从该仓库的账号提出)。
  • 将本站用于推广与插件功能无关的内容。

下架会在本站公开记录原因(涉及投诉人隐私的细节除外)。除上述情形外,我们不会因为某个插件和其他插件功能相近、或与本站运营者有竞争关系而拒绝收录。

4. 一视同仁:排序、标签与推荐

  • 目录内的插件没有推荐位、没有付费置顶,也没有广告位。唯一例外是本社区自己维护的「Zotero中文社区」插件,它在插件广场顶部单独展示,不参与排序和计数,不接受其他插件申请这一位置。目录内的所有插件使用同一套排序,由你选择:GitHub 星标(热度)、最近更新、更新频率(近一年有发布的天数,同一天发布多次只算一天)、累计下载量、名称。首页的「星标最多」「更新最勤」「下载最多」三个榜单直接取自这些排序,不另设算法。
  • 每张卡片固定四个标签,全部由公开数据算出:
    1. 分类:每个插件归入一个主分类(AI、阅读、元数据、界面、附件、集成、笔记、工具、写作、可视化)。
    2. 适配版本:根据作者在发布信息里声明的 Zotero 版本范围判断。「兼容范围未声明」不等于不兼容,只是作者没有写,请到项目主页确认。
    3. 维护状态:按最近一次发布距今分档——90 天内「近期更新」、1 年内「维护中」、2 年内「更新放缓」、超过 2 年「久未更新」。
    4. 人气档位:按 GitHub 星标分档——3000 及以上「热门」、500 及以上「常用」、100 及以上「成长中」、其余「小众」。人气只代表热度,不代表质量。
  • 标签只是提示;是否下架只看第 3 章写明的条件。
  • 社区官方插件单独展示(唯一例外):本社区自己维护的「Zotero中文社区」插件在插件广场顶部单独展示,不在插件目录里,不参与排序和计数,也不影响其他插件的收录与排序规则;这一位置不接受其他插件申请。

5. 数据来源与更新

  • 初始收录名单与中文摘要整理自 zotero-chinese/zotero-plugins 项目的公开插件目录(MIT 协议),署名与许可证见仓库中的 第三方声明。
  • 星标数、版本号、发布日期、安装包地址来自各项目在 GitHub 上的公开页面。
  • 数据由维护者定期更新,页面上方会显示「数据更新于」的日期。两次更新之间,星标和版本可能与项目主页略有出入,以项目主页为准。
  • 本站不托管任何安装包。下载按钮是指向作者发布页的直链,下载时请留意域名是 github.com 或 gitee.com。
  • 目录数据也以 JSON 公开:/data/catalog.json,欢迎自由引用,请注明来源。

6. 如何申请收录、更正或下架

请在公开仓库提交 Issue:https://github.com/cnzotero/zotero-community/issues/new。请写清楚:

  • 申请收录:插件名称、仓库地址、适配的 Zotero 版本、一两句用途说明。
  • 更正信息:哪个插件、哪一项不对、正确的信息和依据。
  • 申请下架:插件名称、你与该项目的关系(作者 / 权利人 / 使用者)、下架理由。

我们会在 Issue 里公开回复处理结果。任何人都可以看到处理过程。

7. 期刊查询的数据与使用规则

  • 指标范围:影响因子、五年影响因子、JCI、JCR 分区与学科排名、中科院分区(升级版与基础版)、SCIE / SSCI / EI 收录,以及 CCF、AJG、FT50、UTD24、北大核心、CSSCI、CSCD 等榜单。
  • 数据版本:所有指标来自同一份数据,版本号显示在每本期刊的详情里。榜单每年更新,以发布机构的最新公布为准。
  • 没有数据就显示「暂无」,不推算、不估计、不用相近期刊的数据顶替。
  • 不展示未经核实的负面名单。预警类名单口径复杂、逐年变化,在能逐条核实来源与年份之前不在本站展示。
  • 数据仅供参考。投稿前请到期刊官网和发布机构核对最新要求与指标。
  • 使用限制:每次查询最多返回 20 条,服务有访问频率限制,不提供批量下载。请勿用程序批量抓取。
  • 不对期刊做主观评级,不做付费置顶,不收取期刊或编辑部的任何推广费用。

8. 免责声明

收录不代表对插件的安全性、稳定性或质量的背书。安装第三方插件前请自行评估,并建议先备份文献库。本站是社区自发运营的非官方站点,与 Zotero 官方无隶属关系;Zotero 是 Corporation for Digital Scholarship 的商标。
