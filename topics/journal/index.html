Zotero 期刊分区与影响因子插件

这类插件在文献列表里显示期刊的分区、影响因子或收录情况。选择时可核对指标来源与数据版本，不同来源口径并不相同；选刊和投稿前请以期刊官方及目标机构的最新要求为准。

← 返回插件广场

共 16 款,按 GitHub 星标排序,与分类页使用同一规则。收录规则：插件名称或简介中出现「期刊」「journal」「影响因子」「分区」「impact factor」「jcr」等词。所有插件按同一规则判断，不看作者、不看星标，没有人工指定。
