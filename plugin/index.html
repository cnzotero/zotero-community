Zotero中文社区插件

在 Zotero 里直接浏览、搜索本站收录的插件,核对来源后一键安装或更新。当前版本 v1.0.0,适配 Zotero 7–10。

下载安装 图文使用教程

它能做什么

  • 在 Zotero 里浏览本站插件广场收录的插件,按名称、简介或作者搜索,按分类筛选。
  • 默认只显示声明适配你当前 Zotero 版本的插件;排序与本站一致:星标最多、最近更新、更新最勤、下载最多。
  • 显示每个插件在本机的状态:已安装、可更新或未安装。
  • 安装或更新前弹出确认框,写明插件名、版本、来源仓库和安装包地址,你确认后才安装。

安装四步

  1. 打开 v1.0.0 发布页,下载 zotero-community.xpi(不要下载源码压缩包)。
  2. 打开 Zotero,在菜单栏选「工具 → 插件」,点右上角的齿轮,选「从文件安装附加组件…」。
  3. 选择刚下载的 zotero-community.xpi,按提示完成安装。
  4. 回到文库界面,点工具栏里搜索框左侧的「插件市场」按钮,即可打开。

使用流程

  1. 浏览目录
  2. 筛选适配的插件
  3. 核对来源后确认
  4. 安装完成

适配版本

适配 Zotero 7 至 10 的桌面版。Zotero 发布新的大版本后,我们验证通过再发布新版本把适配范围放宽;插件会通过 Zotero 自带的更新检查收到新版本。

隐私

  • 打开插件市场时读取本站公开的插件目录;Zotero 检查本插件更新时读取本仓库在 GitHub 上的更新信息。
  • 只有在你确认安装后,才从确认框里显示的仓库下载安装包。
  • 不收集、不上传任何个人信息,也不读取你的文献库。

常见问题

插件市场会自动安装或更新其他插件吗?

不会。每次安装或更新都要你在确认框里核对并确认。

为什么有的插件没有安装按钮?

可能是它没有适配你当前 Zotero 版本的安装包,或者安装包不在它自己的 GitHub 仓库里。可以点「查看详情」到本站的插件页,再去作者主页核对。

入口在哪里?「工具」菜单里能找到吗?

入口在文库工具栏、搜索框左侧。需要在「工具」菜单里也显示入口的,可在 Zotero 设置的「高级 → 设置编辑器」里搜索 zotero-community.showToolsMenuItem,改为 true 后重启 Zotero。

插件广场为什么把它单独放在顶部?

它是本社区自己维护的工具,所以单独展示、明确标注;它不在插件目录里,不参与排序与排名,也不影响其他插件的收录与排序,见收录规则第 4 章。

开源与反馈

插件以 MIT 许可证开源,源代码见 GitHub 仓库。问题与建议欢迎在仓库提交 Issue。
