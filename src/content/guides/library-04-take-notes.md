# 笔记：条目笔记、独立笔记与从标注生成笔记

适用 Zotero 版本：桌面版 7 及以上。笔记标签页等功能只在较新版本才有，文中会单独注明。

最后核对于 2026-11-17。核对方式：Zotero 官方文档、官方发布说明，以及 Zotero 官方源代码中的简体中文界面文本。以下操作均**未实测**，菜单名称请以自己界面上的实际显示为准。

## 你要解决什么

读文献时的想法如果只写在纸上或散落在别的软件里，写论文时很难找回出处。Zotero 的笔记直接存在文库里，可以挂在某篇文献下面，也可以独立存在；还能把 PDF 上的标注整理成笔记，每段引文自动带上出处，点一下就能回到原文那一页。

本文讲三件事：两种笔记有什么区别、怎么建；怎样从标注生成笔记；笔记里的引文怎么用。

## 操作步骤

### 1. 先分清两种笔记

官方文档把笔记分成两种：[官方说明：笔记](https://www.zotero.org/support/notes)

- **子笔记**（也叫条目笔记）：属于某一条文献，显示在该条目下方，也会出现在它的「笔记」区块里。适合写「这篇文章讲了什么、我怎么看」。
- **独立笔记**：不属于任何条目，和其他条目并列显示在文库中。适合写跨多篇文献的综述思路、某一章的提纲。

独立笔记也能和条目建立「关联」，官方关联条目说明里列出的用法之一，就是把独立笔记连到它讨论的那些条目上，具体做法见[整理文库教程](/guides/organize-library)第 8 步。

### 2. 新建子笔记

任选一种方式：

1. 选中一条文献，点中间栏上方的「新建笔记」按钮，选建子笔记的选项（官方文档英文为 Add Child Note；中文界面中可能显示为「添加子笔记」或「新建条目笔记」）。
2. 在右侧条目窗格的「笔记」区块点添加按钮。
3. 右键点击条目，选「添加笔记」。

新建后，右侧会出现笔记编辑器，**边写边自动保存**。想要更大的编辑空间，可以点编辑器里的「在单独窗口编辑」。Zotero 8 起，笔记还可以在标签页中打开，铺满整个窗口；默认双击笔记就会在标签页打开，如果更喜欢独立窗口，可在设置「常规」中勾选「在新窗口而不是标签页中打开笔记」。[Zotero 8 发布说明](https://www.zotero.org/blog/zotero-8/)

### 3. 新建独立笔记

点中间栏上方的「新建笔记」按钮，选「新建独立笔记」。官方分类说明提到，新建的条目会自动存进当时选中的分类；先选中某个课题的分类再建独立笔记，就能和这个课题的文献放在一起。

笔记也能像普通条目一样打标签、建关联，入口在笔记编辑器底部。

### 4. 在阅读器里，把标注整理成笔记

这是 Zotero 笔记最省事的用法。先按[阅读与标注教程](/guides/read-and-annotate)在 PDF 上做好标注，然后：[官方说明：阅读器与笔记](https://www.zotero.org/support/pdf_reader)

1. 在阅读器右上角点笔记按钮，打开笔记窗格，可以在这里新建笔记或打开已有笔记。
2. 要把这份 PDF 的**全部标注**一次生成笔记：点窗格里的「+」按钮，选「通过注释添加条目笔记」（生成子笔记）或「通过注释添加独立笔记」。
3. 要**挑着放**：在笔记窗格里打开一条笔记，边写边把 PDF 页面上或左侧「注释」侧栏里的标注拖进去；也可以选中一条或多条标注，右键选「添加至笔记」。
4. 只引用一次、不想先做标注的句子：在 PDF 里选中文字，直接拖到打开着的笔记里。

### 5. 在条目列表里批量生成

不打开阅读器也行：

- 右键点击一条文献，选「通过注释添加笔记」，会用它附件上的全部标注生成一条子笔记。
- 选中多条文献，右键选「通过注释创建笔记」，会把这些文献的标注汇总成一条独立笔记。适合做文献综述时把几篇文章的要点放到一起。

### 6. 在笔记里使用引文

从标注加进笔记的内容不只是文字，还带着出处信息：

- 点击笔记里的标注文字，在弹出菜单中选「在页面显示」，会打开原 PDF 并跳到做标注的那一页。
- 点击引注，选「显示条目」，会在文库中定位到这篇文献。
- 想在笔记里看到标注原来的颜色，点笔记编辑器右上角的「…」按钮，选「显示注释颜色」；同一菜单里也可以统一隐藏或显示引注。

官方说明指出，这些引注之后可以通过 Word、LibreOffice 或 Google Docs 的 Zotero 插件，随笔记一起插入文档，并自动生成参考文献。Zotero 9 起，文字处理软件插件还新增了 Add Annotation 按钮（中文名称以实际显示为准），可以不经过笔记，直接把标注插进文档，同样带有可自动更新的引注。[Zotero 9 发布说明](https://www.zotero.org/blog/zotero-9/)

如果想改变标注进入笔记时的格式（例如把高亮原文放成引用块），官方提供了笔记模板功能，需要在高级设置的配置编辑器中修改，适合愿意动手的读者。[官方说明：笔记模板](https://www.zotero.org/support/note_templates)

## 常见问题

**笔记会占用同步空间吗？** 官方说明：笔记随题录信息一起同步，不计入 Zotero 文件存储空间配额。但笔记里嵌入的图片会同步到其他设备，并且计入存储空间配额。

**怎么在笔记里搜索？** 笔记内容可以用主窗口的搜索框搜到。在单条笔记里查找文字，用笔记编辑器的查找替换功能，或按 Ctrl/Cmd + F。

**笔记能拿到 Markdown 软件里用吗？** 据 Zotero 6 发布说明，笔记有单独的快速复制设置，可以选「Markdown + 富文本」或 HTML；可以把笔记从条目列表复制或拖到外部编辑器，标注会带着指回 Zotero 条目和 PDF 页码的链接。[Zotero 6 发布说明](https://www.zotero.org/blog/zotero-6/)

**子笔记和独立笔记，该用哪个？** 只关于一篇文献的内容写成子笔记，跟着文献走，不容易丢；综合多篇文献的思考写成独立笔记，再用「关联」连到相关文献。两者可以搭配使用。
