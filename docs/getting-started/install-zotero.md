# 安装 Zotero 与第一个文库

![](../assets/cover-01-install-zotero.png)

适用 Zotero 版本：桌面版 7 及以上，具体系统要求以官方下载页为准。

最后核对于 2026-11-11。核对方式：官方文档；以下桌面操作**未实测**，菜单翻译可能随版本变化。

## 你要解决什么

先完成一个小目标：在自己的电脑上打开 Zotero，建立一个主题分类，加入一篇可以核对的公开论文。暂时不装第三方插件，也不急着搬入全部资料。这样能分清软件是否正常、题录是否准确，以及附件是否真正保存成功。桌面程序与浏览器里的 Zotero Connector 是两件配合使用的工具，安装时不要把其中一个误认为另一个。[官方下载与安装说明](https://www.zotero.org/support/installation)

## 操作步骤

### 1. 从官方页面选择安装文件

打开 [Zotero 下载页](https://www.zotero.org/download/)，按自己的操作系统选择桌面程序，并阅读该系统的安装说明。不要从广告页或不明网盘下载所谓的整合版。完成安装后先启动一次，确认看到文库主窗口，再考虑后续功能；遇到系统阻止时应核对来源，不要盲目关闭系统保护。

<!-- 截图:官方下载页的桌面程序与浏览器工具位置，不含个人账号 -->

### 2. 为浏览器安装配套工具

在同一官方下载页找到适合自己浏览器的 Zotero Connector，并按浏览器的提示完成安装。它用来把网页上的文献信息保存到 Zotero，不是桌面插件安装包。先阅读浏览器显示的权限说明；如果单位设备不允许安装扩展，请遵循设备管理规定，不要寻找不明替代品。

<!-- 截图:浏览器中可识别的 Zotero Connector 入口 -->

### 3. 新建一个小主题分类

在 Zotero 左侧选择自己的文库，通过新建分类的入口建立一个清楚的主题，例如「课程阅读」。分类用于整理条目，同一条文献可以属于多个分类，不需要复制多份。先只建一个分类，避免还没收集资料就做出难以维护的复杂层级。[官方分类说明](https://www.zotero.org/support/collections_and_tags)

<!-- 截图:演示文库中一个新建分类与空条目列表 -->

### 4. 保存并核对一篇公开论文

在浏览器打开一篇公开论文的正式介绍页，使用 Connector 保存，并确认保存到刚建的分类。回到 Zotero，对照原页面检查标题、作者、年份与期刊名；再查看是否有附件、附件是否能打开。没有全文不等于题录保存失败，也不要为补全文去不明网站提交自己的账号。

<!-- 截图:公开论文页面与保存后题录对照，使用演示资料 -->

## 常见问题

**必须先注册账号吗？** 本机收集与整理可以先进行；需要多设备同步时，再按[官方同步说明](https://www.zotero.org/support/sync)设置自己的账号。

**分类里的论文也是一份新副本吗？** 同一文库内，分类更像整理清单。先在「我的文库」核对条目，不要仅凭多个分类中都出现就判断重复。

**页面按钮与本文不同怎么办？** 先记录版本与操作系统，核对[官方基础用法](https://www.zotero.org/support/quick_start_guide)，再反馈差异，勿把相似按钮当成同一操作。
