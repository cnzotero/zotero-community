## 怎么阅读与反馈

按当前任务选择一篇即可，不需要先安装所有插件。教程中的截图注释是拍摄清单，不代表已验证的界面；未实测的步骤不能当成版本适配承诺。恢复文库等涉及已有资料的操作，请先保存现状，核对官方说明后再进行。

发现版本不符、步骤缺失或链接错误，请用[问题表单](https://github.com/cnzotero/zotero-community/issues/new?template=report-plugin-issue.yml)注明篇目、版本与实际结果。补写方法见[贡献指南](../CONTRIBUTING.md)。

官方参考：[安装说明](https://www.zotero.org/support/installation)、[基础用法](https://www.zotero.org/support/quick_start_guide)、[帮助文档](https://www.zotero.org/support/)。返回[项目说明](../README.md)。
