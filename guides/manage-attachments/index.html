附件管理：存储文件、链接文件与自动重命名

文库整理与阅读第 6 篇 / 共 9 篇约 6 分钟读完发布于 2026-11-17更新于 2026-11-17

适用 Zotero 版本：桌面版 7 及以上。自动重命名在 Zotero 7 与 Zotero 8 之间有明显变化，文中会分别说明。

最后核对于 2026-11-17。核对方式：Zotero 官方文档、官方发布说明与更新日志，以及 Zotero 官方源代码中的简体中文界面文本。以下操作均未实测；附件相关菜单在不同版本中名称略有差异，请以自己界面上的实际显示为准。

你要解决什么

PDF 等附件是文库里最占空间、也最容易出问题的部分：文件到底存在哪、能不能同步、删了条目文件还在不在、为什么列表里显示的是「PDF」而不是文件名。这些问题的答案，几乎都取决于附件是「存储文件」还是「链接文件」。

本文先讲清这两种方式的区别，再讲怎样添加和找到附件，最后讲 Zotero 的自动重命名。官方说明：添加文件

操作步骤

1. 先分清「子附件」和「独立附件」

附件可以挂在一条文献下面（子附件），也可以单独存在（独立附件）。官方建议尽量让文件作为子附件存在：独立附件没有题录信息，不能用来引用，很多检索功能也用不了。

拖入的 PDF 若没能自动识别成正式条目，会以独立附件留下。补救办法见把文献加进 Zotero 的几种方式第 3 步。

2. 再分清「存储文件」和「链接文件」

存储文件（默认，官方强烈推荐）

  • 文件会被复制到 Zotero 数据目录里，由 Zotero 统一管理。
  • 使用文件同步时，会自动在你的各台设备之间同步，也能在 zotero.org 的网页版文库中使用。
  • 在 Zotero 里删除这个附件条目时，文件也会被一并删除。
  • 因为是复制，原来那份文件还在原处；官方建议可以删掉原件，免得两份混淆。

链接文件

  • Zotero 只记住文件在你电脑上的位置，文件本身留在原处。
  • 链接文件不会同步；在 Zotero 里删除附件条目时，原文件也不会被删除。
  • 不能在群组文库中使用，因为无法保证其他成员能访问同一个路径。官方文档还写明 iOS 应用不支持链接文件。

官方的态度很明确：为了获得最顺畅的体验，强烈推荐使用存储文件；链接文件属于进阶用法，官方无法针对个人的具体配置提供排错帮助。

3. 添加附件的几种方法

拖放： 从系统的文件管理器把文件拖进 Zotero。

  • 拖到中间列表中已有的条目上：成为它的子附件。
  • 拖到分类上，或拖到列表空白处、条目之间：成为独立附件。
  • 默认是复制（存储文件）。想改为链接，拖放时按住 Ctrl + Shift（Windows/Linux）或 Cmd + Option（Mac）。官方提示 Mac 上可能需要先让 Zotero 窗口切到最前，修饰键才会生效。

按钮： 选中一条文献，点中间栏上方的回形针「添加附件」按钮，选附加文件副本或附加文件链接的选项（官方文档英文为 Attach Stored Copy of File / Attach Link to File；较新版本的中文界面可能显示为「附加文件…」「附加文件链接…」）。右键点击条目选「添加附件」也能找到同样的选项。不选条目、想新建独立附件，则在「新建条目」按钮的菜单中操作。

网页链接： 同一菜单中还可以附加网址链接，指向某个网页或本机其他程序（例如笔记软件）的地址。注意「链接」和「快照」不同：链接只保存网页标题、网址和访问日期，要看内容得回到原网站；快照会把当时的网页保存一份到本机。官方说明：链接与快照的区别

4. 找到附件文件

  • 双击条目或附件，即可打开。
  • 想在系统文件管理器里看到文件，右键点击附件，选「打开文件目录」（英文为 Show File）。
  • 存储文件放在 Zotero 数据目录下，每个文件都有一个以 8 位随机字符命名的独立子文件夹。

需要在 Zotero 之外使用存储文件时，官方建议先在 Zotero 里找到条目，再把附件直接拖出去（例如拖进邮件），或用「打开文件目录」找到文件。也可以用系统自带的搜索功能找；因为 Zotero 会按题录给文件改名，按标题、作者或年份都能搜到。

5. 想把链接文件改成存储文件

在「工具」菜单的「管理附件」中，选「转换已链接文件为已存储文件…」。转换后，这些文件就由 Zotero 管理并参与同步。

如果你在多台电脑上用网盘等外部工具同步链接文件，官方建议在设置中配置「已链接附件的根目录」，这样即使文件夹在不同电脑上的位置不同，Zotero 也能找到文件。官方说明：找不到链接文件

6. 理解自动重命名

Zotero 会按上级条目的题录（作者、年份、标题等）自动给附件文件改名。官方说明：文件重命名

哪些文件会被改名：

  • 从网上保存的文件（通过浏览器连接器、按标识符添加，或官方文档所说的 Find Available PDF 查找全文功能）一律会被改名。
  • 默认情况下，给条目添加的第一个存储 PDF 或 EPUB，以及成功识别出元数据的文件，也会被改名。
  • 条目已经有附件时，后来再加的文件不会自动改名，以免改掉补充材料的文件名。
  • 链接文件默认不改名，可在设置中打开「重命名链接的文件」。
  • 可以通过「重命名这些类型的文件」调整对哪些文件类型生效。
  • 不想自动改名，在设置的「常规」中取消对应选项（Zotero 7 中英文为 Automatically rename attachment files using parent metadata，Zotero 8 起为「自动重命名文件」）。

Zotero 7 与 Zotero 8 的区别：

  • Zotero 7 及更早：只在文件刚加入时改名。之后修改了题录（比如改了标题），需要右键附件选 Rename File from Parent Metadata 手动更新文件名。
  • Zotero 8 起：修改题录后，文件名会自动跟着更新；原右键菜单项已移除。若某个文件名与设定的格式不一致（例如关闭了自动改名），附件窗格中文件名旁会出现「重命名文件以匹配上级条目」按钮。升级到 Zotero 8 后，旧文件不会被自动批量改名，但可以在设置中一次性全部改名；更改文件名格式时，Zotero 也会提示是否重命名所有文件。Zotero 8 发布说明

自定义文件名格式： 默认格式是「作者（1～2 位）- 年份 - 标题」，在设置的「常规」中可以自定义。官方给出的默认模板是：

{{ firstCreator suffix=" - " }}{{ year suffix=" - " }}{{ title truncate="100" }}

模板支持截断、大小写转换、条件判断等，完整的变量和参数列表见官方文件重命名说明。Zotero 9 起，群组管理员还可以为每个群组文库单独设置重命名规则，让成员的文件名保持一致。Zotero 9 发布说明

7. 附件标题和文件名是两回事

很多人发现：文件明明已经改名了，列表里却只显示「PDF」。这是正常的。官方说明

  • 附件有两个名字：列表里显示的附件标题，和磁盘上的文件名。
  • 上级条目那一行已经显示了标题、作者等信息，所以 Zotero 给附件用更简短的标题，例如「PDF」「Full Text PDF」，避免列表重复冗长。
  • 点击附件，在右侧窗格中可以同时看到并修改标题和文件名。
  • Zotero 8 起，如果确实想在列表中看到文件名，可在设置「常规」中打开「在条目列表中显示附件文件名」；还可以在「工具」→「管理附件」中用「规范附件标题…」，把以前被改成文件名的旧附件标题统一改回「PDF」这类简短标题。

常见问题

删除附件条目，电脑上的文件会被删吗？ 存储文件会被删除（先进回收站，参见整理文库教程第 4 步）；链接文件不会，原文件留在原处。

链接文件提示找不到怎么办？ 官方列出的常见原因有三种：文件在 Zotero 之外被移动或删除了（可移回原处，或在「找不到文件」对话框中用定位按钮重新指定）；某台电脑上的「已链接附件的根目录」设置不对；文件还没通过你自己的同步工具传到这台电脑（Zotero 只同步存储文件）。

可以自己去数据目录里改文件名、挪文件吗？ 官方文档没有提供这种做法。存储文件由 Zotero 管理，建议通过 Zotero 自己的重命名功能处理，不要手动改动数据目录中的内容。备份与恢复请参见同步、备份与附件有什么区别。
