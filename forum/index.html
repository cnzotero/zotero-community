发帖前建议附上的 4 项信息（更快定位原因）

在 GitHub Discussions 提问时，复制下面模板填完关键信息，其他用户和维护者通常一轮就能帮定位原因（发图前请遮挡个人账号与本地隐私路径）：

1. 操作系统与版本：例如 Windows 11 / macOS 15
2. Zotero 版本号：例如 Zotero 8.0.x 或 10.0.x（在「帮助 → 关于 Zotero」查看）
3. 涉及插件及版本：例如某插件 vX.Y.Z（或未使用第三方插件）
4. 复现步骤与现象：做了哪一步操作 → 期望结果 → 实际报错文字或截图

高频问答

遇到 Zotero 报错或插件无法安装，去哪里提问能最快得到帮助？

可在 Zotero 中文社区的 GitHub Discussions（github.com/cnzotero/zotero-community/discussions）按分类发帖交流；提问时附上操作系统、Zotero 完整版本号（如 8.0 / 10.0）、插件名称与版本、复现步骤及完整报错截图（注意遮挡个人路径与账号）。

升级 Zotero 8 或 Zotero 10 后旧插件变灰不可用，文献和笔记会丢吗？

不会。文献条目、PDF 原文件和高亮笔记保存在本地数据目录中，插件禁用不会删除文献。可先去本站「按 Zotero 版本」页面确认该插件是否已发布新版适配，再决定更新、暂缓或替换为同类活跃插件。

在 Word 或 WPS 里找不到 Zotero 选项卡怎么快速恢复？

先彻底关闭 Word / WPS，再打开 Zotero「设置 → 引用 → 文字处理软件」点击重新安装加载项；若仍未显示，检查 Word 的「禁用项目」与「Word 加载项」是否勾上 Zotero.dotm，或按站内 Word/WPS 排错教程手动复制模板文件。

Zotero 提示 300MB 存储空间已满，会影响本地添加文献吗？

不影响本地使用，也不会限制题录、笔记与标签的云端数据同步。300MB 仅限制官方云端 PDF 附件存储；需要多设备同步大量 PDF 时，可将个人文库的附件同步改为 WebDAV，并定期保留本地完整数据目录备份。

想申请收录新插件，或者发现某个插件的兼容版本写错了怎么办？

直接在公开仓库 github.com/cnzotero/zotero-community 提交 Issue。符合收录条件的 GitHub 插件申请会由公开脚本自动核对并收录，信息更正与下架申请会公开回复处理结果。
